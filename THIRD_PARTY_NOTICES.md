# Attribution and license status

## Research material

Kim Chul, Paper VIII: Dual-Layer Topological Neuromorphic and Signal Processing Architecture, reviewed Korean translation dated October 1, 2026, with appended Paper IX on PLP signal/image processing. The separate English version is dated September 16, 2026. `docs/paper_review.md` records source hashes, page boundaries, and the public-domain dedication stated in those files. No original PDF, source-page rendering, or full extracted paper text is distributed here. The owner's confirmation of the requested `(1)` edition is outstanding.

## Example images

`results/images/camera_clean.png` is derived from scikit-image's current `data.camera()` image. The scikit-image documentation identifies it as CC0 by photographer Lav Varshney. The noisy and processed camera images and animation crops are derived from that example. The text chart is generated by this project. Reference: [scikit-image data documentation](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.camera).

## Software and rendering

Python dependencies are installed by the user and are not vendored in this repository. Their licenses remain upstream; an installed metadata inventory is generated in `results/dependency_licenses.json`. The inventory is descriptive and is not a substitute for upstream license files. NumPy, SciPy, scikit-image, Pillow, OpenCV, imageio, psutil and imageio-ffmpeg are credited as the numerical, image, measurement and encoding libraries used by this project.

The supplied environment uses platform fonts already installed on the host; no font files are redistributed. Rendering falls back to DejaVu Sans where available. MP4s were encoded using the FFmpeg executable supplied by imageio-ffmpeg and its libx264 encoder. No codec or FFmpeg binary is redistributed in this repository.

Project-wide licensing remains pending in `LICENSE`; the repository must not claim an OSI-approved project license until the owner chooses and verifies one.
