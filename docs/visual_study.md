# Expanded image study and ablation

## Scope and provenance

The v3 study preserves the original two-image experiment and all its raw data. `results/archive/pre-v3-db8bbe5/` stores the pre-redesign measurements; Git branch `backup/pre-visual-redesign-db8bbe5` retains the complete earlier code, README and media. The original two GIFs also remain available. Current expanded results use new filenames rather than silently replacing old measurements.

The source PDF was reread, including Paper VIII pages 1-5 and the appended Paper IX pages 6-9. The arithmetic identities and Listing 2 remain directly reproducible. The PLP potential, entropy probability estimator, finite contour/time discretization and reconstruction operator are still insufficiently specified to derive a complete image algorithm. The reviewed sources do not supply a complete image-processing executable, raw source image benchmark, PDK/synthesis evidence or usable archive DOI. `paper_review.md` and `source_alignment.md` document these boundaries.

## Content classes and fixed experiment

Six images are declared before comparing results: a CC0 camera photograph (real texture), the legacy text/line/dot chart, a new small-font chart (12/16/22/30/42 pixels), a dense line/grid chart, high-contrast geometry, and a dark texture scene derived as `0.02 + 0.18*camera`. The four synthetic/derived fixtures are generated by `src/benchmark/visual_study.py`. This is not a general natural-image dataset or a physical camera sensor-noise study.

Every image uses three normalized Gaussian noise sigmas (0.03, 0.06, 0.10) and three seeds (20261020-20261022): 54 noisy cases. Noise is clipped to [0,1]. All methods receive the identical float32 array for a given case and use fixed settings. Known noise sigma is supplied to Bilateral and both prototypes. OpenCV is single-threaded. Two warm-ups and seven randomized repetitions are used per callable. Timings include complete callable allocations; metrics and file I/O are excluded. The platform and core dependency versions are recorded in `environment.json`; the expanded run metadata is in `visual_study/run.json`.

The conventional methods remain Gaussian 5x5/sigma=1, Bilateral diameter=7/intensity_sigma=2*noise_sigma/spatial_sigma=2, and Median 3x3. Bilateral is the predeclared visual representative because it is an edge-aware classical baseline; it is not selected as a best or worst method after evaluating outputs. Gaussian and Median remain in the full CSV.

## Why the earlier output could look soft

1. Local Wiener shrinkage pulls uncertain pixels toward a 5x5 local mean. Near a small letter or thin line, the local variance can mix structure and noise; detail can be attenuated even in this first pass.
2. Legacy V1 then guided-smooths the already denoised image with a second 5x5 model. That extra spatial operation can suppress residual noise and improve PSNR/SSIM, but can also reduce gradients and fine texture. The effect is content-dependent rather than a universal failure of guided filtering.
3. Its Point stage rounds intensity to 1024 levels. The maximum nearest-rounding intensity error is approximately 1/(2*1023). This does not reconstruct lost detail, recover sub-pixels, or implement a Dirac localization operator. It is not a substantive denoising mechanism.
4. V1 evaluates six box-filter calls across its Wiener/guided passes, plus array expressions, casts and quantization; V2 uses two box-filter calls. This explains additional work; it is not a measured instruction-level profile. The native arithmetic benchmark concerns phase products and must not be used as an image-filter acceleration claim.

## V1 retained; V2 is a tradeoff variant

Legacy V1 is preserved unchanged. The existing `prototype` function remains its implementation. V2 uses only the same Wiener estimator followed by the same 10-bit intensity quantizer, removing guided smoothing. `wiener_plane` is tested for bitwise equality to V1's original first-stage output. V2 is available as `prototype_v2`; it does not silently replace the old default.

V2 is deliberately simpler: lower work and potentially less edge attenuation, at the cost of more residual noise. The supplied full-suite results show better average edge fidelity and lower runtime, but worse average PSNR and SSIM. Thus it is not called a universal improvement or a faithful PLP engine. Both are **PLP-Inspired Experimental Prototype - Not a Validated Implementation of the Original PLP Equations**.

`noise_ablation.csv` separately evaluates local mean, Wiener float output and Wiener+guided float output. `expanded_noise.csv` adds quantized V1/V2 and all conventional filters. Each ablation has a separately timed full callable; timings are not obtained by subtracting medians. `noise_ablation_samples.csv` and `expanded_noise_samples.csv` retain every repetition. Compare the float Wiener/guided outputs with their respective quantized variants to see the small effect of 10-bit rounding.

## Visualization selection and fair display

The noise GIF uses the predeclared microtext image, sigma=0.06, first seed. Its V2-minus-Bilateral PSNR gain is ranked against every case in `representative_case.json`. In this run V2 has lower PSNR than Bilateral for the displayed case; that result is shown unchanged. A negative result is useful evidence of the tradeoff, not a reason to replace it with a favorable example.

The final image-first noise revision uses two large synchronized panels: Noisy Input and a completed Bilateral or V2 output, plus a clean-reference crop. The reveal line is an editorial wipe, not algorithm iterations. A later detail tour includes line grid, geometry and dark texture. All compared methods share the same crop, magnification and intensity mapping. Later absolute-error heatmaps use one fixed clipped range [0,0.20]; edge maps are absolute differences of 3x3 Sobel gradient magnitudes with range [0,1.0]. Their magma colors are never independently normalized. Removed-intensity maps identify changes that can include both noise and signal, rather than claiming every changed pixel is lost detail. PSNR/SSIM/edge values use full-resolution float32 outputs, not enlarged or PNG-quantized displays. [Final revision timeline and display policy](noise_visual_revision.md).

The ablation GIF also shows geometry and the dark derived camera scene. The latter uses a shared display gain of 1/0.22 for visibility; the metrics still use the original [0,1] intensities. Profile plots show actual horizontal intensity samples, not enhanced/sharpened replacements. All summary means cover the full 54-case suite; they are arithmetic means of per-case PSNR and of per-case timing medians, not pooled-MSE PSNR or pooled timing medians.

## Limitations

The custom strong-edge fidelity score is defined in `methodology.md`; it can favor residual noise and is not a sufficient quality criterion alone. No clean reference enters the filters. This experiment does not establish general image-quality superiority, color/RAW processing, motion recovery, prime-orbit cancellation, entropy absorption, super-resolution, physical PIM performance or hardware power. Obtaining the missing discrete PLP operator and source experiment artifacts remains necessary before claiming a faithful implementation.
